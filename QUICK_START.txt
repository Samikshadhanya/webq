🚀 SETUP IN 4 STEPS:

STEP 1: Install Dependencies
────────────────────────────
npm install

STEP 2: Create .env.local
────────────────────────────
Create a file named ".env.local" in the project root and add:

VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id

(Replace with your actual Firebase credentials from Firebase Console)

STEP 3: Initialize Firestore Database
──────────────────────────────────────
node scripts/setupFirestore.js

This will:
- Create Firestore collections (quizzes, users, etc.)
- Add 3 sample quizzes with questions
- Create a demo user profile
- Setup everything automatically

STEP 4: Run the App
──────────────────
npm run dev

Visit: http://localhost:5173

🆘 TROUBLESHOOTING:

Problem: Dashboard shows loading forever
Solution: 
  1. Check .env.local has correct Firebase credentials
  2. Run: node scripts/setupFirestore.js
  3. Refresh the page

Problem: Quiz list is empty
Solution:
  1. Go to Firebase Console
  2. Check Firestore Database
  3. Verify "quizzes" collection exists with documents
  4. Run setup script again if needed

Problem: Login fails
Solution:
  1. Check Firebase Console Authentication is enabled
  2. Verify Email/Password provider is active
  3. Check .env.local credentials

Problem: Settings modals don't show
Solution:
  1. Check browser console for errors
  2. Ensure Profile.tsx loaded correctly
  3. Verify Framer Motion is installed
