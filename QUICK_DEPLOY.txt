⚡ 3-STEP DEPLOYMENT (10 MINUTES TOTAL):

STEP 1: Create Free Neon Database (5 minutes)
────────────────────────────────────────────
→ Go to: https://neon.tech
→ Click "Sign Up" (use GitHub for fastest)
→ Create a new project (name it "quiz-master")
→ Go to "Connection" tab
→ Select "Pooled connection"
→ COPY the full connection string
  (looks like: postgresql://user:password@ep-xxxxx.region.neon.tech/...)

STEP 2: Add Environment Variables to Vercel (2 minutes)
──────────────────────────────────────────────────────
→ Go to: https://vercel.com/dashboard
→ Select your project (Samikshadhanya/webq)
→ Click: Settings → Environment Variables

Add THREE variables (paste these exactly):

   NAME: POSTGRES_PRISMA_URL
   VALUE: [Paste your Neon connection string from Step 1]
   SAVE

   NAME: POSTGRES_URL_NON_POOLING
   VALUE: [Paste same Neon connection string]
   SAVE

   NAME: JWT_SECRET
   VALUE: quiz-master-secret-2024
   SAVE

STEP 3: Deploy to Vercel (3 minutes)
────────────────────────────────────
→ Option A (Recommended):
   Click "Publish" button in v0 interface
   Select GitHub repository
   Click Deploy

→ Option B (Alternative):
   Go to Vercel Dashboard
   Your project will auto-redeploy with new env vars

→ WAIT 2-3 MINUTES for deployment to complete
   (Check "Deployments" tab for "READY" status)

❓ TROUBLESHOOTING:

   Q: "Connection refused" error?
   A: Check your Neon connection string is correct. Wait 1 minute and try again.

   Q: Deployment stuck on "Building"?
   A: Normal - takes 2-3 minutes. Watch the Vercel dashboard.

   Q: No quizzes showing up?
   A: Visit yoururl.com/api/init in browser to trigger database init.

   Q: Can't log in?
   A: Make sure you signed up first. Accounts aren't pre-created.

   Q: "Database does not exist"?
   A: Wait 2 minutes after deploying. Database creates on first access.
