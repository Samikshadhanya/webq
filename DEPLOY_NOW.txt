🚀 DEPLOY IN 3 STEPS:

STEP 1: Connect your GitHub Repository
─────────────────────────────────────
1. Push this code to your GitHub repository
2. Go to: https://vercel.com/new
3. Select your GitHub repository
4. Click "Import"

STEP 2: Add Environment Variables in Vercel
───────────────────────────────────────────
Add these 3 variables in the "Environment Variables" section:

1. POSTGRES_PRISMA_URL
   Value: postgresql://user:password@db.neon.tech/dbname
   (Get this from your Neon project)

2. POSTGRES_URL_NON_POOLING
   Value: postgresql://user:password@db.neon.tech/dbname
   (Same as above)

3. JWT_SECRET
   Value: Generate a random 32+ char string
   (Example: aB3$cD4%eF5^gH6&jK7*lM8(nO9)pQ0!)

Then click "Deploy"

STEP 3: Initialize Database
──────────────────────────
After deployment completes:

Option A - Using Browser:
1. Visit: https://your-deployment-url.vercel.app
2. Open Developer Tools (F12)
3. Go to Console tab
4. Paste and run:
   fetch('/api/init', { method: 'POST' })
     .then(r => r.json())
     .then(data => console.log(data))

Option B - Using cURL (if you have it):
curl -X POST https://your-deployment-url.vercel.app/api/init

You should see:
{
  "success": true,
  "credentials": {
    "email": "admin@quizmaster.com",
    "password": "admin123"
  }
}

❓ TROUBLESHOOTING:

ISSUE: Deployment failed
SOLUTION: Check Vercel build logs. Make sure Node.js version is 18+

ISSUE: Database connection error
SOLUTION: Verify Neon URL format and network access settings in Neon

ISSUE: Login not working after deployment
SOLUTION: Run the /api/init endpoint again to initialize database

ISSUE: Init endpoint returns error
SOLUTION: Check that POSTGRES_PRISMA_URL is set in Vercel env vars
